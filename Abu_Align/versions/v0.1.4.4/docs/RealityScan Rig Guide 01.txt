Please update the 360 cubemap splitting workflow to generate RealityScan/RealityCapture sidecar XMP metadata files alongside each extracted cubemap image.

### Background & Objective:
We are splitting 360 equirectangular frames into 6 rectilinear cubemap faces (front, back, left, right, up, down) at 90° horizontal/vertical FOV (pinhole, 0 distortion).
The trajectory positions have a 0 to 30 cm uncertainty, but the relative 90° orthogonal orientation and shared camera center (0, 0, 0 translation offset) between the 6 faces are mathematically exact. 

We need to output an `.xmp` sidecar file for EVERY extracted image so that RealityScan treats the 6 faces of each frame as a rigid camera rig and allows the whole rig to optimize its position without the 6 faces drifting apart.

### File Requirements:
1. Every exported image (e.g., `frame_0001_front.jpg`) must have an accompanying sidecar file with identical name: `frame_0001_front.jpg.xmp` placed in the same folder.
2. The XMP file must follow the RealityCapture/RealityScan XML schema:

```xml
<x:xmpmeta xmlns:x="adobe:ns:meta/">
  <rdf:RDF xmlns:rdf="[http://www.w3.org/1999/02/22-rdf-syntax-ns#](http://www.w3.org/1999/02/22-rdf-syntax-ns#)">
    <rdf:Description xmlns:xcr="[http://www.capturingreality.com/mxmp/1.0/](http://www.capturingreality.com/mxmp/1.0/)">
      <!-- Rig Definition -->
      <xcr:RigId>cubemap_rig</xcr:RigId>
      <xcr:RigInstanceId>{FRAME_ID}</xcr:RigInstanceId>
      
      <!-- Calibration Priors (Ideal 90-degree rectilinear pinhole) -->
      <xcr:FocalLength35mm>18.000000</xcr:FocalLength35mm>
      <xcr:PrincipalPointU>0.000000</xcr:PrincipalPointU>
      <xcr:PrincipalPointV>0.000000</xcr:PrincipalPointV>
      <xcr:DistortionModel>brown3</xcr:DistortionModel>
      <xcr:DistortionCoeficients>0 0 0 0 0 0</xcr:DistortionCoeficients>
      <xcr:CalibrationPrior>locked</xcr:CalibrationPrior>
      <xcr:LensDistortionPrior>locked</xcr:LensDistortionPrior>

      <!-- Trajectory & Pose Priors -->
      <!-- Absolute position from our SLAM/GPS trajectory -->
      <xcr:Position>{POS_X} {POS_Y} {POS_Z}</xcr:Position>
      <!-- Row-major 3x3 rotation matrix combining frame world pose + face orthogonal rotation -->
      <xcr:Rotation>{R00} {R01} {R02} {R10} {R11} {R12} {R20} {R21} {R22}</xcr:Rotation>
      
      <!-- Crucial: Set PosePrior to 'approximate' so the 10-30cm error can be solved as a rigid body -->
      <xcr:PosePrior>approximate</xcr:PosePrior>
      <xcr:PoseAccuracyPosition>0.300000 0.300000 0.300000</xcr:PoseAccuracyPosition>
      <xcr:PoseAccuracyRotation>0.001000 0.001000 0.001000</xcr:PoseAccuracyRotation>
    </rdf:Description>
  </rdf:RDF>
</x:xmpmeta>
